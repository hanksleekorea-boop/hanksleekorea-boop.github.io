Each answer includes the next action you can take.

Does Free require sign-in or a credit card?

No. The current free workspace requires neither sign-in nor a credit card.

Is the public workspace really $0?

Yes. The current local workspace has no monthly charge, payment, or platform fee.

Is the generated link a live affiliate revenue link?

No. It is a basic tracking link that validates a public destination and adds UTM and LinkMax reference values.

Where is my service information stored?

When you save, it stays in this browser on this device and is not automatically sent to a LinkMax server.

Can any affiliate network connect immediately?

No. The current public Free release does not provide affiliate enrollment, approval, or live revenue connections.

Is sample revenue real money?

No. Sample and simulation values exist for learning and UI validation.

Why is live revenue shown as zero?

Approved and payable revenue remain zero without verified provider evidence.

Does this release process payment or payout?

No. The current public Free release executes no payment, billing, refund, or payout.

Is there a click limit?

The workspace does not collect server-side clicks, so it does not enforce a click limit.

How do I create my first link?

Choose a role and service type, enter a public HTTP(S) URL, and run the safety check.

What if link creation fails?

Use a public HTTP(S) URL. URLs with credentials, localhost, and .local hosts are rejected.

Does it replace my existing affiliate link?

No. The original address is not modified; a separate basic tracking link is created.

Can I use it on mobile?

Yes. The same release candidate passed on physical Android 15 and Android 8.1 devices. Physical iPhone evidence is not yet available.

Can I export my data?

Yes. Export free JSON containing the version, evidence state, and limitations.

Can I delete device data?

Yes. After explicit confirmation, only FAC workspace data is deleted; other LinkMax data is preserved.

What must never be entered into a Fit Link?

비밀번호, API 비밀키, 쿠키, 신분증, 계좌정보, 개인 고객 명단, 전체 데이터베이스 덤프 must not be entered.

How long does the Fit workspace take?

The basic diagnostic target is 3~5 minutes, and unknown answers may be left as unknown.

How long is Fit workspace data retained?

Free Fit workspace data stays only on this device until the user deletes it. There is no automatic server retention.

Where do I contact support?

Help and Trust provide self-service guidance. Operator-bound support submission is not part of the current public Free release.

Is revenue guaranteed?

No. Route selection and simulations support decisions but do not guarantee purchases, approvals, or revenue.
