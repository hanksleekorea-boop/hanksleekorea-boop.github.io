시작·오류·돈·권리를 한곳에서 찾으세요

질문을 열면 바로 할 수 있는 행동까지 안내합니다.

무료판에 로그인이나 신용카드가 필요한가요?

아니요. 현재 무료 작업대는 로그인과 신용카드 없이 사용할 수 있습니다.

무료판 비용은 정말 $0인가요?

예. 현재 공개된 로컬 작업대에는 월 사용료, 결제, 플랫폼 수수료가 없습니다.

생성한 링크가 실제 제휴 수익 링크인가요?

아니요. 공개 목적지를 검사하고 UTM과 LinkMax 참조값을 붙인 기본 추적 링크입니다.

입력한 서비스 정보는 어디에 저장되나요?

저장을 누른 경우 이 브라우저의 이 기기에만 저장되며 LinkMax 서버로 자동 전송되지 않습니다.

아무 제휴망이나 바로 연결되나요?

아니요. 현재 무료 공개판은 제휴망 가입·승인·실수익 연결을 제공하지 않습니다.

샘플 수익은 실제 돈인가요?

아니요. 샘플과 시뮬레이션 수치는 학습과 화면 검증용입니다.

왜 실제 수익은 $0으로 표시되나요?

검증된 공급자 증거가 없기 때문에 승인·지급 가능 수익을 0으로 표시합니다.

결제나 지급 기능이 있나요?

아니요. 현재 무료 공개판에서는 결제·청구·환불·지급을 실행하지 않습니다.

클릭 수 제한이 있나요?

현재 작업대는 서버 클릭을 수집하지 않으므로 클릭 한도도 적용하지 않습니다.

첫 링크는 어떻게 만드나요?

무료 작업대에서 역할과 서비스 유형을 고르고 공개 HTTP(S) 주소를 입력한 뒤 안전 검사 버튼을 누릅니다.

링크 생성이 실패하면 어떻게 하나요?

HTTP(S) 공개 주소인지 확인하세요. 사용자명·비밀번호 포함 주소, localhost와 .local 주소는 거부됩니다.

기존 제휴 링크를 바꾸나요?

아니요. 원래 주소는 수정하지 않으며 새 기본 추적 링크를 별도로 만듭니다.

모바일에서도 사용할 수 있나요?

예. Android 15와 Android 8.1 실제 기기에서 동일 출시 후보를 검사했습니다. iPhone 실제 기기 증거는 아직 없습니다.

자료를 내려받을 수 있나요?

예. 판번호, 자료 상태와 한계가 포함된 JSON 파일로 무료 내보낼 수 있습니다.

기기 자료를 삭제할 수 있나요?

예. 삭제 확인을 선택한 뒤 FAC 작업 자료만 삭제하며 다른 LinkMax 자료는 지우지 않습니다.

Fit Link에는 무엇을 입력하면 안 되나요?

비밀번호, API 비밀키, 쿠키, 신분증, 계좌정보, 개인 고객 명단, 전체 데이터베이스 덤프는 입력하지 않습니다.

Fit 작업대 작성에는 얼마나 걸리나요?

기본 진단 목표는 3~5분이며 모르는 항목은 모름으로 남길 수 있습니다.

Fit 작업 자료는 얼마나 보관하나요?

무료 Fit 작업 자료는 이 기기에만 남고 사용자가 삭제할 때까지 유지됩니다. 자동 서버 보관은 없습니다.

문의는 어디에서 하나요?

현재는 도움말과 신뢰센터의 셀프서비스 안내를 제공합니다. 운영자에게 자동 전송되는 지원 접수는 아직 제공하지 않습니다.

수익이 보장되나요?

아니요. 경로 선택과 시뮬레이션은 판단을 돕지만 구매, 승인, 수익을 보장하지 않습니다.
