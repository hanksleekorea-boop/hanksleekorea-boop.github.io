무료 공개판과 요금

현재 공개된 로컬 작업대는 $0이며 로그인과 신용카드가 필요하지 않습니다. 실제 제휴 수수료, 결제, 청구, 환불 또는 지급은 처리하지 않습니다.

기본 추적 링크와 제휴 고지

생성 주소는 UTM과 LinkMax 참조값을 포함한 기본 추적 링크이며 실제 제휴 승인을 뜻하지 않습니다. 향후 사용자가 제휴 링크나 광고를 연결할 때에는 화면에서 제공하는 관계 고지문을 함께 게시해야 합니다.

개인정보와 자동 수집

무료 작업대에 입력한 서비스명·역할·목적지 주소·계획은 저장 버튼을 누른 경우 이 기기의 브라우저 저장소에만 남고 LinkMax 서버로 자동 전송되지 않습니다. 호스팅 사업자는 보안과 전달을 위해 IP 주소, 요청 시각, 브라우저 정보와 보안 쿠키를 통상적인 접속 기록으로 처리할 수 있습니다.

금지 정보

비밀번호, API 비밀키, 쿠키, 신분증, 계좌정보, 개인 고객 명단, 전체 데이터베이스 덤프를 무료 작업대나 Fit 작업대에 입력하지 마세요.

보존·내보내기·삭제

LinkMax는 무료 로컬 작업 자료의 서버 사본을 보관하지 않습니다. 사용자는 JSON으로 내보내고 명시적 확인 후 해당 작업 자료만 삭제할 수 있습니다. 브라우저 자료 삭제나 기기 교체 뒤에는 LinkMax가 복구할 수 없습니다.

외부 링크와 책임

사용자가 입력한 목적지와 생성 링크는 외부 사이트로 연결될 수 있습니다. 외부 사이트의 상품, 가격, 개인정보 처리, 합법성 또는 이용 가능성을 LinkMax가 보증하지 않으며 사용자는 게시 전 주소와 고지 의무를 직접 확인해야 합니다.

도움말과 운영 지원

현재 공개판은 도움말·신뢰센터와 로컬 Fit 내보내기를 제공합니다. 운영자에게 자동 전송되는 지원 사건, 긴급 대응 시간 또는 서비스 수준 보장은 제공하지 않습니다.

수익 보장 없음

샘플과 시뮬레이션은 학습·검증용이며 구매, 승인, 수익 또는 지급을 보장하지 않습니다. 관할 법률에 따른 소비자 권리는 이 운영정책으로 제한하지 않습니다.
