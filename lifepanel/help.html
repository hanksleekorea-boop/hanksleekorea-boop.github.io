30초 첫 사용

  1. 내 상황부터 고르기에서 지금과 가까운 상황을 선택합니다.
  2. 에너지·부담·기분을 고르고 상태 반영을 누릅니다.
  3. 최대 세 행동 중 하나를 완료·더 작게·미루기·휴식·도움 요청으로 처리합니다.
  4. 원하면 돌아보기 질문을 고르고, 원하지 않으면 건너뜁니다.

저장·사본·복원

  • 설정과 기록은 이 브라우저의 기기 안 저장소에 있습니다. 브라우저 자료 삭제, 기기 고장, 비공개 모드 종료 때 사라질 수 있습니다.
  • 판번호 사본 내보내기로 JSON 파일을 정기적으로 받으세요. 파일에는 개인 기록이 들어갈 수 있으므로 안전한 위치에 보관합니다.
  • 사본 파일 복원은 LifePanel에서 만든 파일만 사용하세요. 판번호와 SHA-256이 맞지 않으면 기존 자료를 바꾸지 않습니다.
  • LifePanel 자료 전체 삭제는 확인을 두 번 거친 뒤 LifePanel 전용 값만 지웁니다.

선택 Google 보호본

  1. 계정 상태가 설정되지 않음이면 현재 공개판 운영 설정이 없는 것이며 연결을 시도하지 않습니다.
  2. Google로 연결 뒤 최신 사본 직접 저장을 눌러야 앱 전용 최신 보호본 1개가 생깁니다. 자동 업로드는 없습니다.
  3. 보호본 비교에서 원격·현재 항목 수를 확인합니다. 이 단계에서는 로컬 자료가 바뀌지 않습니다.
  4. 내용을 확인한 뒤에만 비교한 보호본 적용을 누릅니다. 클라우드 삭제는 별도 확인 뒤 실행되고 로컬 자료는 유지됩니다.

초대 전용 응원 모임

운영 서버가 연결된 판은 2~8명 모임을 지원합니다. 실제 연락처 대신 상대가 직접 사용하는 일회용 초대를 전달하세요. 행동 제목·완료 여부·응원 요청만 공유하고 개인 메모·건강·돈·위치 원문은 입력하지 마세요. 원하지 않으면 공유 중단·차단·신고·나가기를 선택합니다.

화면이 기기 안 미리보기라고 표시되면 기능 계약을 시험하는 로컬 화면이며 실제 친구에게 전달되지 않습니다.

설치·오프라인

Chrome·Edge·Samsung Internet 등 지원 브라우저의 메뉴에서 홈 화면에 추가 또는 앱 설치를 선택할 수 있습니다. 첫 방문에서 화면 파일이 준비된 뒤에는 네트워크가 끊겨도 핵심 기기 안 기능을 계속 쓸 수 있습니다. 브라우저가 저장 공간을 회수하면 다시 온라인으로 열어야 할 수 있습니다.

광고 선택과 문제 해결

  • 광고 선택은 개인 기록을 불러오지 않는 무료 자료실에만 있으며 주 앱에는 광고 공급자 코드가 없습니다.
  • 광고 없이 계속을 누르면 외부 광고 공급자를 요청하지 않으며 모든 무료 기능은 그대로입니다.
  • 제한 광고 허용은 실제 사이트 승인·게시자 ID·인증 동의 관리가 준비된 판에서만 광고 요청으로 이어집니다.
  • 브라우저의 GPC 신호, 광고 차단기·네트워크 오류·빈 광고는 LifePanel 저장·추천·복원에 영향을 주지 않습니다.
  • 선택 초기화로 기기 안의 광고 선택을 기본 꺼짐으로 되돌릴 수 있습니다.

결제 제외 고급 기능 7종

  1. 8개 영역 포트폴리오는 오늘의 최대 2개 영역과 별도로 장기 방향을 저장합니다.
  2. 작업 쪼개기는 외부 AI로 보내지 않고 기기 안 규칙으로 작은 단계를 만듭니다.
  3. 장기 실험은 7~365일, 중단 조건과 충분한 변화 신호를 먼저 저장합니다.
  4. 고급 패널은 상세 민감정보 없이 최대 6개 표면을 구성합니다.
  5. 여러 기기 자료 합치기는 사본을 먼저 비교하고 별도 확인 뒤 적용합니다.
  6. 가족·돌봄 계획은 별칭과 직접 고른 루틴만 저장하며 감시 기능이 아닙니다.
  7. 전문가 제한 공유는 최대 30일의 선택 범위 사본이며 언제든 철회할 수 있습니다.
