# 11번가 3,000개 공개 카테고리 스냅샷

이 폴더는 화면 파일과 상품 목록을 분리하기 위한 자리입니다. 실제 상품 자료는 한 파일에 몰아넣지 말고, 카테고리별 JSON 파일로 나누어 둡니다.

넣기 전에는 아래 검사를 반드시 통과해야 합니다.

`python tools/collect_11st_public_catalog.py`

`node verify-catalog-3000-v49.mjs`

`node verify-catalog-trust-contract-v2.mjs`

검사는 정확히 3,000개인지, 16개 큰 범주가 모두 있는지, 중복·가격·11번가 상품/이미지 주소·수집 시각·순위 기준이 올바른지를 확인합니다. 자료의 순위 기준은 11번가 공개 카테고리 화면에 표시되는 `11번가 랭킹순·광고포함`이며, 순수 판매량이나 베스트셀러로 부르지 않습니다.

v2 신뢰 계약은 기존 JSON을 덮어쓰지 않고 메모리에서 새 형식으로 읽습니다. 현재 상품은 상품군·모델·옵션·판매 제안·일치 확신도가 없으므로 3,000개 모두 `검토 필요`이고 자동으로 같은 상품에 묶지 않습니다. 배송·옵션·세금·반품 비용도 근거가 없으면 `미확인`으로 유지하며 총액을 만들지 않습니다.
