서비스로 돌아가기개인정보 원칙접근성 안내분리 상태판

서비스 이용 원칙

현재는 시험 서비스입니다. 운영 주체·공식 지원 채널·상업 운영 개시일이 확정되기 전에는 정식 상업 운영이나 법률 준수를 주장하지 않습니다.

서비스 범위

공개 상품 스냅샷을 탐색·보관·비교하고 판매처로 이동하기 전 판단을 돕습니다. ShoppingScanner는 판매자, 결제대행사, 주문 당사자가 아닙니다.

Google 계정과 기기 간 저장

계정 없이도 서비스를 사용할 수 있습니다. Google 로그인·무료 가입이 완료된 경우에만 사용자가 직접 선택해 저장한 서비스 자료를 계정에 연결할 수 있습니다. Apple·비밀번호 로그인은 제공하지 않습니다. 기기 저장을 서버에 올리는 동작은 사용자가 지금 저장을 누를 때만 수행합니다. ShoppingScanner 표시 이름은 별도 저장 버튼을 눌러야 바뀌며, 언어와 하루 목표는 이 기기에만 저장됩니다.

프로 결정 도구

프로젝트, 점수, 총비용, 목표가, 근거형 도우미, 스마트 조건, 바코드, 보고서, 암호화 백업, 통화 시나리오, 할인·자료 점검과 자료 권리를 결제 없이 제공합니다. 결과는 입력값과 공개 스냅샷에 따른 참고자료이며 품질·사기 여부·구매 적합성을 보증하지 않습니다.

가격·재고·배송

표시 정보는 수집 시점의 스냅샷이며 실시간 최저가를 보장하지 않습니다. 구매 전 판매처에서 가격, 옵션, 재고, 배송, 취소·환불 조건을 다시 확인해야 합니다.

제휴 링크와 보상

현재 제휴 보상 추적은 꺼져 있습니다. 향후 승인된 제휴 링크를 켜면 링크 가까이에 보상 가능성을 표시하며, 상품 ID 외 사용자·기기 식별값을 넣지 않습니다. 주문·결제·취소·환불은 판매처에서 처리합니다.

중단과 복구

연결 중단 시 현재 화면과 기기 저장 정보는 가능한 범위에서 유지합니다. 수동 백업은 사용자가 명시적으로 만들고 가져오기 전 확인합니다.
