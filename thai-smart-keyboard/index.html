태국어를 몰라도 발음부터 시작하세요

영문으로 태국어 발음을 입력하고 후보를 선택하는 무료 웹 도구입니다. 설치 없이 휴대폰과 PC에서 사용할 수 있습니다.

모바일 앱 열기 PC 작업공간 개발 현황

3단계로 입력

1

발음을 영문으로 입력

예: sawatdee처럼 익숙한 로마자로 입력합니다.

2

태국어 후보 확인

입력한 발음에 맞는 태국어 후보를 비교합니다.

3

선택하고 복사

원하는 표현을 확정한 뒤 메시지나 문서에 사용합니다.

무료로 제공되는 핵심 기능

  • 태국어 발음 기반 후보 입력과 빠른 시작 안내
  • 휴대폰용 입력 화면과 PC용 넓은 작업공간
  • QR을 통한 휴대폰 전환과 PWA 홈 화면 설치
  • 개인정보를 최소화한 로컬 우선 설정과 사전
  • 한국어·영어·태국어 안내와 접근성 고려

알아두세요

자동 후보는 문맥과 고유명사를 완벽하게 판단하지 못할 수 있습니다. 계약, 의료, 법률 등 중요한 문장은 태국어 전문가에게 최종 확인하세요. 입력 도구는 번역 서비스가 아니며, 뜻과 높임말은 상황에 따라 달라질 수 있습니다.
